# Logistic Regression

Hands-on Logistic Regression practice exercises using Python in VS Code.

This folder contains practice exercise built using Logistic Regression, applied to different real-world domains.

- Breast-Cancer-Detection: Classifying tumors as malignant or benign using Logistic Regression on diagnostic features
- UTM-Testing (coming soon): Classifying Universal Testing Machine reports into safe, fracture, or yield categories
